# 위험 목록

| R8 | 오래된 epoch가 완료를 기록 | 소유권 역전 | fence 거절은 상태를 유지하고 감사 행만 추가 | 닫힘 |
| R9 | 취소 타임아웃을 취소 완료로 처리 | 아직 움직이는 로봇을 유휴로 봄 | 타임아웃은 `RECOVERY_REQUIRED` | Mock에서 닫힘 |
| R10 | 예약 만료로 구역을 비움 | 점유 중 진입 | 만료는 해제 조건이 아님. 위치 불신은 `blocked` | 정책 테스트 통과. Gazebo 미검증 |
| R11 | 화면 폴링이 조정 작업을 유발 | 관측이 상태를 바꿈 | GET은 롤백 전용 세션 | 닫힘 |

| R13 | SQLite 단일 작성자 한계 | 프로세스를 나누면 락 경합 | Phase 1은 한 프로세스. PostgreSQL은 미실행 | 열림 |
